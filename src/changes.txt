# Texture changes (2026-11-03)

- Fixed the original Ancient Sword Stand's structure rotation and mirroring while preserving its full/empty and opening states. Aligned mining with its iron-tool tag: now pickaxe-mineable and requires an iron-or-better pickaxe for block drops. Right-click reward claiming, one-claymore protection, animation, state-copying loot, hardness, textures and saved IDs are unchanged. Added exhaustive state-transform and harvesting-permission regressions; marked review findings4/5 resolved.

- Replaced Forge/Infusion hard-coded recipe arrays with registered JSON recipe-manager types; migrated all39 Forge and108 Infusion mappings. Added explicit input counts, retained/consumed templates, processing times, component-copy policy and Jade eligibility. Corrected Forge weapon-conversion consumption from a stack-dependent up-to-four ingots to the explicit one-ingot recipe cost; shard forging still costs4 shards.
- Made machine slots, shift-click routing and infusion hints follow synced recipes/tags, including datapack materials/templates. Added component-safe output merging and per-machine persisted recipe/input identity, so recipe replacement/removal or input changes cannot reuse unrelated progress. Removed obsolete array classes, broken Forge serializer/indexing and debug printing.
- Added optional JEI Forge/Infusion categories with recipe quantities, result stacks, processing times, retained-template/Jade notes, machine catalysts and menu-slot transfer mappings. Added the permanent JEI-compatibility rule to AGENTS.md. JEI remains compile-only/optional for release and can be enabled for development using -PwithJei.
- Added data-defined recipe, counts, reload/save progress, output-component and all147 JSON/network-codec regression checks; updated legacy tests to query real recipes and tick machines rather than invoke array-index crafting. Build and all485 GameTests pass both without and with JEI19.21.0.247 installed. Added markdown/machine-recipes.md; the earlier feature review marks the machine-array finding resolved.

- Added Ancient Dagger Pedestal and Ancient Axe Stand (2026-11-05), reusing the Ancient Sword Stand's texture materials. The dagger lies flat on a low cushioned pedestal; the axe sits upright in a braced rack. Each awards its matching rusty weapon once, supports full-inventory drops, and preserves its full/empty state when broken and replaced.
- Added full/empty baked models, all horizontal facings, rotation/mirroring, item models, Miscellaneous creative entries, state-copying loot and iron-pickaxe mining requirements for the new displays. No crafting recipes, natural-generation placements or restoration routes were invented; the original Sword Stand's animation/behavior remains unchanged.
- Added four relic-display GameTests and scripts/check_relic_displays.py for model/texture/variant/loot checks and a geometry preview. Added markdown/feature-review-2026-11-05.md separating confirmed inconsistencies, recommendations and manual follow-ups; existing gameplay was not broadly rebalanced as part of the review.

- Refined the four damask tool heads (2026-11-04) using the damask knife's grayscale palette and alternating light/dark diagonal bands, distinguishing them from carbon steel. Preserved iron silhouettes, Advanced Handle colors, carbon-steel textures and completed knife/sword artwork.

- Added 28 material-colored pickaxe/axe/hoe/shovel sprites for scrap, meteoric iron, reinforced iron, steel, damask, titanium and tungsten, preserving the iron tool silhouettes, transparency and pixel positions. New wooden handles use the actual Advanced Handle item's four-color palette, corrected from the basic Handle per the user's clarification.
- Added matching iron-template swords for meteoric iron and reinforced iron; preserved all completed swords and the carbon-steel pickaxe, axe and hoe. Replaced the carbon-steel shovel's pickaxe-shaped artwork with the proper shovel shape and carbon-steel/Advanced Handle colors.
- Updated 30 ordinary-tool item models to reference their own material artwork instead of iron sprites or axe fallback models. No tool stats, recipes, combat mechanics or special weapon artwork changed.
- Added scripts/recolor_metal_tools.ps1 for reproducible palette conversion, protected-artwork checks, exact silhouette/pixel verification, all-40-tool model checks, optional packaged-PNG hash checks and a nearest-neighbor preview under build/.
